I'm a Kotlin maintainer at JetBrains, working on the Kotlin Gradle and Maven plugins and project import in IntelliJ IDEA. I also build AI tools that investigate failed builds and reproduce reported issues. Before JetBrains I was a Staff Engineer on Delivery Hero's Android platform.

## Selected work

- I designed and implemented [compiler reference indexing for Gradle and Maven builds](https://github.com/JetBrains/kotlin/blob/master/docs/build-tools/compiler-reference-index.md). This cut Find Usages time in IntelliJ IDEA by up to 78%, depending on project size and structure.
- [Kotlin import models](https://github.com/JetBrains/kotlin/tree/master/libraries/tools/kotlin-import-models), targeted for Kotlin 2.5.20: an IDE or an AI coding agent requests the project data it needs from the build system, such as compilation units, dependencies, and compiler arguments, instead of reconstructing it through reflection.
- I changed how [Delivery Hero's Android apps cache images](https://deliveryhero.jobs/blog/how-to-stop-worrying-about-the-image-freshness-and-reduce-the-image-network-traffic/). In one country, daily image traffic fell from about 9 TB to 2 TB.
